Real Estate Manager Android

Android-клиент системы управления недвижимостью.

Приложение разработано полностью на Kotlin и использует современный стек Android Jetpack.

⸻

Возможности

* Управление объектами недвижимости
* Фотографии
* Документы
* Платежи
* Показания счетчиков
* Напоминания
* Центр уведомлений
* Offline-first режим
* Автоматическая синхронизация
* PDF отчеты
* Локальное хранение данных

⸻
